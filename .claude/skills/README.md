# Project skills

This directory holds Claude Code skills scoped to this repo. Each skill is a folder
with a `SKILL.md`:

```
.claude/skills/<skill-name>/SKILL.md
```

Claude Code discovers them automatically. Add a skill when you have a repeatable,
repo-specific task worth teaching the agent, for example "scaffold a new extractor
for a document type" or "generate a fictional sample PDF". Keep skills small and
single-purpose.
